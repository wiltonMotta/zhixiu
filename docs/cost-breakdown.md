## 五、隐性成本提醒

以下成本不体现在云服务账单中，但需要纳入经营预算：

| 隐性成本 | 估算 | 说明 |
|---------|------|------|
| **干洗服务履约** | 金卡200人×1次 + 钻石50人×2次 = 300次/年 | 如外包约30-50元/次 ≈ 9,000-15,000元/年 |
| **线上订单快递费** | 200单/年 × 10元 | ≈ 2,000元/年 |
| **包装材料** | 200单/年 × 4元 | ≈ 800元/年 |
| **积分商城商品成本** | 视商品定价 | 积分兑换商品为自营库存，实为营销成本 |
| **代金券让利** | 视发放量 | 50/100/200元券为线下引流成本 |
| **线下消费积分录入人力** | — | 门店员工每次消费后需在小程序后台手动录单 |

> ⚠️ 干洗服务是最大的隐性成本！
> - 金卡5000元门槛 → 预计200人达标 → 200次干洗
> - 钻石10000元门槛 → 预计50人达标 → 100次干洗
> - 外包干洗约30-50元/次 → 年成本 9,000-15,000元
> - 建议与干洗店谈批量合作价，或自购干洗设备
