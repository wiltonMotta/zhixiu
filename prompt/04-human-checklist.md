# 小程序上线 — 人工必须处理的关键信息与操作清单

> AI Agent可以完成开发、测试、部署等大部分工作，但以下事项必须由人工亲自处理，
> 涉及法律主体、金融账户、实名认证、物理设备等AI无法替代的环节。

---

## 一、微信小程序注册与认证（🚫 AI无法完成）

### 1.1 小程序账号注册

| 事项 | 说明 | 所需材料 | 预计耗时 |
|------|------|---------|---------|
| 注册微信小程序 | 在mp.weixin.qq.com注册 | 企业营业执照 | 1-3天 |
| 主体认证 | 企业主体信息认证 | 营业执照、法人身份证、对公账户 | 1-5个工作日 |
| 微信认证 | 每年300元认证费 | 同上 + 认证公函 | 1-5个工作日 |

**关键信息需要人工准备**：
- [ ] 企业营业执照（经营范围需包含：服装销售/服饰零售/互联网销售）
- [ ] 法人身份证正反面照片
- [ ] 对公银行账户信息（用于认证打款验证）
- [ ] 企业公章（用于认证公函盖章）
- [ ] 运营者身份证 + 手机号 + 微信号（作为管理员）
- [ ] 小程序名称（建议：致秀会员 / 致秀服饰会员）
- [ ] 小程序简介（需包含关键词以提高搜索曝光）
- [ ] 小程序Logo（建议400×400px，PNG透明底）
- [ ] 服务类目选择：商家自营 > 服装/鞋帽/箱包

### 1.2 小程序类目与资质

```
必选类目：
✅ 商家自营 - 服装/鞋帽/箱包（需营业执照）
✅ 商家自营 - 洗护/家饰/家纺（干洗服务需要）

可选类目（视业务需要）：
⬜ 工具 - 会员管理
⬜ 生活服务 - 服饰/皮具养护

⚠️ 注意：
- 类目一旦添加，修改需审核
- 涉及"会员卡"功能需要额外资质
- 如涉及食品/保健品等洗护周边，需对应食品经营许可证
```

## 二、微信支付商户号申请（🚫 AI无法完成）

### 2.1 商户号申请

| 事项 | 说明 | 所需材料 | 预计耗时 |
|------|------|---------|---------|
| 申请微信支付商户号 | 在pay.weixin.qq.com申请 | 营业执照、法人身份证、对公账户 | 1-5个工作日 |
| 商户号与小程序绑定 | 在小程序后台关联商户号 | 管理员扫码确认 | 即时 |
| 开通产品权限 | JSAPI支付、退款等 | 在商户平台开通 | 即时-1天 |

**关键信息需要人工准备**：
- [ ] 营业执照注册号/统一社会信用代码
- [ ] 法人姓名 + 身份证号
- [ ] 对公银行账户：开户银行 + 银行账号 + 开户支行
- [ ] 商户简称（支付时展示给用户，如"致秀服饰"）
- [ ] 联系人姓名 + 手机号 + 邮箱
- [ ] 商户号申请通过后，记录：**商户号(mch_id)**
- [ ] API密钥设置（商户平台 → API安全 → 设置API密钥）
- [ ] API证书下载（商户平台 → API安全 → 申请API证书）

### 2.2 支付密钥配置（⚠️ 高度敏感，人工操作）

```
以下密钥信息必须人工设置，切勿通过AI工具传递或存储在代码仓库中：

1. 商户号 (mch_id)
2. API密钥 (api_key) — 32位自定义字符串
3. API证书 (apiclient_cert.pem + apiclient_key.pem)
4. 支付回调URL设置：
   https://{your-domain}/api/v1/payment/wechat/callback
   
操作路径：商户平台 → API安全 → 设置
```

## 三、服务器与域名（🚫 AI无法完成购买，但AI可配置）

### 3.1 云服务器与域名

| 资源 | 推荐方案 | 操作 | 预计费用 |
|------|---------|------|---------|
| 云服务器 | 腾讯云CVM 2核4G | 人工购买 | ~100元/月 |
| 域名 | .com域名 | 人工购买+ICP备案 | ~70元/年 |
| SSL证书 | 腾讯云免费DV证书 | 人工申请（AI可配置） | 免费 |
| 对象存储 | 腾讯云COS | 人工开通（AI可配置） | ~0.1元/GB/月 |
| Redis | 腾讯云Redis | 人工购买 | ~50元/月 |
| PostgreSQL | 腾讯云PostgreSQL | 人工购买 | ~80元/月 |

**人工必须操作**：
- [ ] 购买域名
- [ ] 域名ICP备案（必须，微信小程序强制要求，耗时10-20天）
- [ ] 域名SSL证书申请
- [ ] 腾讯云COS开通与Bucket创建
- [ ] 服务器购买与基础环境配置

**⚠️ ICP备案是最大时间瓶颈，建议第一优先处理**

### 3.2 小程序服务器域名配置

```
登录 mp.weixin.qq.com → 开发 → 开发管理 → 开发设置 → 服务器域名

需要配置：
request合法域名：  https://{your-domain}
socket合法域名：   （暂不需要）
uploadFile合法域名：https://{your-domain}
downloadFile合法域名：https://{your-cos-domain}.cos.{region}.myqcloud.com

⚠️ 域名必须ICP备案通过后才能配置
⚠️ 必须使用HTTPS
```

## 四、微信订阅消息模板（🚫 人工申请，AI可调用）

### 4.1 需要申请的订阅消息模板

|---------|----------------|---------|---------|

- [ ] 配置到后端环境变量中

## 五、法律合规与隐私（🚫 AI无法承担法律责任）

### 5.1 必须人工签署/准备的文件

| 文件 | 说明 | 建议 |
|------|------|------|
| 用户协议 | 小程序注册时需用户同意 | AI可起草，律师审核，人工发布 |
| 隐私政策 | 必须明确告知用户数据收集范围 | AI可起草，律师审核，人工发布 |
| 会员服务条款 | 会员等级/积分/权益说明 | AI可起草，人工确认 |
| 退款政策 | 线上商品退款规则 | 人工制定 |

### 5.2 数据合规要点

```
⚠️ 以下必须人工确认：
- [ ] 用户手机号获取需用户主动授权（微信手机号快速验证组件）
- [ ] 生日信息收集需明确告知用途
- [ ] 积分数据存储合规
- [ ] 是否需要等保认证（一般C端不需要，但建议咨询）
- [ ] 个人信息保护影响评估（PIA）
```

## 七、小程序上线审核流程（🚫 人工提交审核）

### 7.1 上线前检查清单

```
代码层面（AI可完成）：
✅ 所有功能开发完成
✅ 所有测试通过
✅ 风控逻辑验证通过
✅ 支付流程端到端验证
✅ 性能压测通过

配置层面（人工确认）：
- [ ] 服务器域名已配置
- [ ] 微信支付已绑定
- [ ] 订阅消息模板已申请
- [ ] 隐私政策已上线
- [ ] 用户协议已上线

业务层面（人工确认）：
- [ ] 至少有3个品牌的商品已上架
- [ ] 积分商城至少有10个商品
- [ ] Banner图已配置
- [ ] 门店信息已配置
- [ ] 客服入口可用
```

### 7.2 小程序提审操作

```
1. 登录 mp.weixin.qq.com
2. 版本管理 → 提交审核
3. 填写审核信息：
   - 功能页面：首页/品牌商城/积分中心/我的
   - 测试账号：（如需登录才能体验）
   - 功能介绍文案
4. 等待审核（1-7天，通常1-3天）
5. 审核通过 → 发布上线
6. 审核驳回 → 根据原因修改 → 重新提交

⚠️ 常见驳回原因：
   - 虚拟商品（积分商城需注意：实物兑换可过审，纯虚拟服务可能被拒）
   - 会员卡功能无对应类目
   - 隐私政策缺失
   - 支付功能异常
   - 涉及"干洗服务"需有对应经营资质
```

### 7.3 上线后人工必做

```
1. 小程序发布后，在门店张贴小程序码引导老客注册
2. 线下收银系统与小程序积分系统对接测试
3. 第一批线下消费积分手动录入验证
4. 观察首周运营数据，调整积分商城商品
5. 收集老客反馈，优化UI交互
```

## 八、关键密钥与敏感信息清单（🔐 最高安全等级）

> ⚠️ 以下信息绝不能提交到代码仓库、不能通过AI工具传递、必须由人工安全保管

| 信息 | 存储位置 | 管理方式 |
|------|---------|---------|
| 微信小程序 AppID | 小程序后台 | 记录在安全文档 |
| 微信小程序 AppSecret | 小程序后台 | 仅存于服务端环境变量 |
| 微信支付商户号 | 商户平台 | 记录在安全文档 |
| 微信支付 API密钥 | 商户平台 | 仅存于服务端环境变量 |
| 微信支付 API证书 | 商户平台下载 | 仅存于服务器指定目录 |
| 数据库连接密码 | 云服务商 | 仅存于服务端环境变量 |
| Redis密码 | 云服务商 | 仅存于服务端环境变量 |
| COS SecretKey | 腾讯云 | 仅存于服务端环境变量 |
| JWT签名密钥 | 自定义 | 仅存于服务端环境变量 |
| Admin API Token | 自定义 | 运营Agent使用，定期轮换 |

**环境变量模板（.env.example，可提交到仓库）**：
```bash
# 微信小程序
WX_APPID=your_appid_here
WX_SECRET=your_secret_here

# 微信支付
WX_PAY_MCH_ID=your_mch_id_here
WX_PAY_API_KEY=your_api_key_here
WX_PAY_CERT_PATH=/path/to/apiclient_cert.pem
WX_PAY_KEY_PATH=/path/to/apiclient_key.pem

# 数据库
DATABASE_URL=postgresql://user:password@host:5432/zhixiu

# Redis
REDIS_URL=redis://:password@host:6379

# 腾讯云COS
COS_SECRET_ID=your_secret_id_here
COS_SECRET_KEY=your_secret_key_here
COS_BUCKET=zhixiu-assets
COS_REGION=ap-shanghai

# JWT
JWT_SECRET=your_jwt_secret_here

# Admin
ADMIN_API_TOKEN=your_admin_token_here
```

## 九、上线时间线（关键路径）

```
Week 1-2: 📋 人工准备阶段
  ├── 注册小程序账号 + 认证
  ├── 申请微信支付商户号
  ├── 购买域名 + 开始ICP备案（最长20天）
  ├── 准备营业执照等资质文件
  └── 准备品牌素材、商品数据

Week 2-6: 💻 AI Agent开发阶段（与人工准备并行）
  ├── 架构师Agent：数据库设计 + API设计
  ├── 后端Agent：模块开发 + 风控实现
  ├── 前端Agent：小程序 + 后台管理
  ├── 测试Agent：风控专项测试
  └── 运维Agent：CI/CD + 部署配置

Week 4-5: 🔧 集成调试阶段
  ├── 微信支付接入测试（需人工提供密钥）
  ├── 订阅消息配置
  ├── 服务器域名配置（需ICP备案通过）
  └── 端到端功能验证

Week 5-6: 📦 上线准备阶段
  ├── 商品数据录入（运营Agent执行）
  ├── 隐私政策/用户协议上线
  ├── 小程序提审
  └── 门店物料准备

Week 6+: 🚀 上线运营阶段
  ├── 小程序发布
  ├── 线下引导老客注册
  ├── 运营Agent持续运营
  └── 监控与优化
```

**⚠️ 关键瓶颈：ICP备案需10-20天，务必第一周就启动！**
